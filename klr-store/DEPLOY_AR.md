# دليل النشر بالعربية

1. جهّز خادماً يدعم Node.js 20+ واتصالاً دائماً بالإنترنت.
2. ارفع المجلد وثبّت الاعتماديات عبر `npm install`.
3. أنشئ `.env` من `.env.example` وضع الأسرار داخله فقط.
4. اربط نطاقاً وفعّل HTTPS من مزود الاستضافة أو Reverse Proxy.
5. اجعل `data/` و`uploads/` على مساحة دائمة ومحمية، وليسا ضمن مجلد ملفات الموقع العامة.
6. شغّل `npm start` للموقع و`npm run bot` للبوت كخدمتين منفصلتين مع إعادة تشغيل تلقائية عند التعطل.
7. اختبر التسجيل، إنشاء طلب، رفع إيصال تجريبي، مراجعة الإدارة، تحديث الحالة، والتذكرة قبل الإطلاق.
8. فعّل النسخ الاحتياطي، وغيّر كلمة مرور المدير، ولا تضع مفاتيح Discord في أي ملف داخل `public/`.

إذا كانت المنصة المجانية توقف التطبيقات عند الخمول أو تمسح القرص المؤقت، فهي غير مناسبة لتشغيل بوت دائم أو حفظ قاعدة البيانات والإيصالات.
